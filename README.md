# TOOLZIP

로그인 없이 사용하는 반응형 도구 모음 웹사이트 초안입니다.

## 포함된 기능
- 글자 수 세기, 계산기, 퍼센트 계산, 날짜 계산, 단위 변환
- 랜덤 뽑기, 팀 나누기, 랜덤 숫자, 룰렛
- 타이머/스톱워치, 메모장, 할 일 목록
- 번역(온라인 Google 번역 페이지 연결), 비밀번호 생성, 텍스트 비교
- 이미지 압축/크기 변경, 즐겨찾기, 최근 사용, 다크 모드, 백업 내보내기
- PWA 서비스 워커를 통한 기본 오프라인 캐시

## 실행 방법
가장 간단하게는 `index.html`을 브라우저에서 열어 기본 기능을 확인할 수 있습니다.
오프라인 캐시와 설치 기능은 HTTPS로 호스팅해야 정상 작동합니다.

## 무료 배포 방법 (GitHub Pages)
1. GitHub에 로그인하고 새 public repository를 만듭니다.
2. 이 폴더 안의 파일 5개(index.html, style.css, app.js, manifest.json, sw.js)를 업로드합니다.
3. Repository Settings → Pages → Deploy from a branch → `main` / root를 선택하고 저장합니다.
4. 몇 분 뒤 표시되는 `https://계정이름.github.io/저장소이름/` 링크를 친구들에게 공유하면 됩니다.

## 오프라인 관련 주의
- 계산·랜덤·타이머·메모·할 일·텍스트 비교·이미지 처리 등은 로컬 기능입니다.
- 번역은 온라인 서비스가 필요합니다.
- 사이트를 처음 열 때 인터넷 연결이 필요하며, HTTPS로 한 번 방문해 파일이 캐시된 뒤 오프라인 사용이 가능합니다.
- 메모와 목록은 해당 브라우저/기기에 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있으니 백업 기능을 이용하세요.
