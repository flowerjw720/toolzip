# TOOLZIP 2.0

반응형 올인원 도구 웹사이트입니다. 로그인 없이 사용할 수 있고, 즐겨찾기·메모·할 일 목록은 브라우저의 로컬 저장소에 저장됩니다.

## 포함 기능
- 계산기, 퍼센트 계산기, 날짜 계산기, 단위 변환기
- 환율 계산기 (인터넷 연결 시 공개 환율 API 사용, 연결 실패 시 참고 환율 표시)
- 글자 수 세기, 텍스트 비교, Google 번역 연결
- 랜덤 뽑기, 랜덤 팀 나누기, 랜덤 숫자, 회전 애니메이션 룰렛
- 타이머/스톱워치, 메모장, 할 일 목록, 비밀번호 생성
- 검색, 카테고리, 즐겨찾기, 최근 사용, 다크 모드
- PWA 서비스 워커 캐시

## GitHub Pages 업데이트
1. GitHub의 `toolzip` 저장소를 엽니다.
2. `Add file` → `Upload files`를 선택합니다.
3. 압축을 푼 폴더 안의 `index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `README.md`를 업로드합니다.
4. 기존 파일과 이름이 같으면 덮어쓰고 `Commit changes`를 누릅니다.
5. `Settings` → `Pages`에서 `main` / `/(root)`가 설정되어 있는지 확인합니다.
6. 사이트 주소: https://flowerjw720.github.io/toolzip/

업데이트가 반영되기까지 몇 분 걸릴 수 있습니다. 캐시 때문에 옛 화면이 보이면 브라우저를 새로고침하거나 캐시를 지워 보세요.

## 참고
- 환율은 참고용이며 은행/환전소 환율 및 수수료와 다를 수 있습니다.
- 번역 기능은 Google 번역 웹사이트를 엽니다.
- 외부 환율 API 및 Google Fonts는 인터넷이 필요합니다.
- 브라우저 데이터를 삭제하면 로컬 메모/할 일/즐겨찾기가 지워질 수 있습니다.
